2 · Android App — Layered Architecture

📱 UI Layer — HDFC Bank Clone (React Native / Jetpack Compose)

Pixel-faithful clone of HDFC banking app. Every screen captures biometric signals invisibly in the background.

Login — typing cadence Dashboard — touch heatmap Transfer — keystroke timing Settings — usage patterns

🔧 Sensor Abstraction Layer — 39 Sensors (Background Service)

Runs silently as a background service. Polls hardware sensors at 1–200 Hz. Events buffered in circular arrays.

MotionCollector — Accel+Gyro 100Hz TouchCollector — X/Y/Pressure/Velocity LocationCollector — GPS+WiFi+BLE EnvCollector — Light+Proximity+Baro BiometricCollector — Fingerprint+Face+PPG SystemCollector — Screen+Battery+Apps

⚡ Edge Processing — On-Device (Privacy-Preserving)

Raw sensor data NEVER leaves the device. Features computed locally: mean, std, FFT, DTW gestures. Privacy filter strips PII.

Feature Extractor → 300 floats/2s TFLite pre-screener SQLite ring buffer (10MB) GPS→geohash-6 | Mic→energy only

6 · ML Training & Prediction Pipeline

📝 Enrollment (Sessions 1–5)

User performs normal banking. All sensor events labeled GENUINE. LSTM autoencoder trained on 300-float feature vectors. Model + scaler + threshold stored in MLflow registry. Baseline profile cached in Redis.

5 sessions to enroll LSTM Autoencoder P99 threshold calibration

🔍 Live Inference (Every 2s)

Feature vector scored against enrolled model. Reconstruction error → risk_score. Per-sensor anomaly flags raised at 3σ. Score formula: 0.6×ML + 0.25×anomaly + 0.15×context.

Redis model cache (2ms hot) End-to-end <200ms Isolation forest for new patterns

🔄 Continuous Retraining

Confirmed-genuine sessions added to training corpus. Nightly Airflow DAG fine-tunes model (LR=0.0001). New model validated on holdout → canary deploy 10% for 24h → promote. Drift detection: 7-day rising error triggers re-enrollment.

Nightly retraining Canary deploy Drift detection No catastrophic forgetting
7 · Risk Decision Matrix
0.00 – 0.30 ✅ ALLOW

Transparent. Session continues. No user interruption. Event logged to audit trail.

0.30 – 0.55 🟡 FLAG

Log only. Visible to fraud ops in dashboard. Used for model retraining data.

0.55 – 0.70 🟠 STEP-UP

Silent biometric re-auth (fingerprint/face). If fail → OTP to registered mobile.

0.70 – 0.85 🔴 HIGH-RISK

Biometric + OTP required. Maker-checker for transfers > ₹1L. Digital signature logged.

0.85 – 1.00 🚫 BLOCK

Session terminated. Transactions cancelled. Account flagged. Ops alert + SMS + email.
